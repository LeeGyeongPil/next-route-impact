# shop-app (practice input)

A tiny Next.js source skeleton used as sample input for `next-route-impact`.
It is not a runnable app: Next.js and React are not installed and it cannot be built.
Its folders cover the routing rules the tool understands: route groups, dynamic and catch-all segments,
a parallel slot, an intercepting route, a route handler, a private folder, the Pages Router and a middleware matcher.
